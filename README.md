## What it is

NationScope is a national statistics portal covering 32 countries. Pick a country and
see its population, GDP, life expectancy, literacy rate, and HDI in one place — then
compare countries side by side, rank them by any indicator, and search the whole
dataset instantly.

Highlights:

- Country profiles with the five headline indicators
- Rankings per indicator, so the best and worst are one click away
- Head-to-head country comparison
- Fast search across all 32 countries

## Run it

```sh
deno task start
```

Then open the local address printed in the terminal.
